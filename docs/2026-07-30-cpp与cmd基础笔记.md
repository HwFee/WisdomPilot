## 一、C++ 编程核心要点（内存与运算符重载）

### 1. `new int[n]` 末尾加括号 `()` 的作用

- **结论**：强制**值初始化**，对 `int` 类型而言就是**将所有元素清零**。
- **对比**：不加括号（`new int[n]`）元素值为垃圾值，极易引发未定义行为。
- **建议**：养成加括号的习惯，或直接用 `std::vector<int>(n, 0)` 更安全。

```cpp
int* a = new int[n];     // 不加()：垃圾值，未定义行为风险
int* b = new int[n]();   // 加()：全部清零
// 更推荐：
std::vector<int> v(n, 0);
```

### 2. `operator[]` 为什么要写两个版本（const 与非 const）

- **结论**：为了支持 **“常量正确性（const-correctness）”**。
  - **非 const 版本**（返回 `int&`）：允许通过下标**修改**数组元素（如 `arr[0]=10`）。
  - **const 版本**（返回 `const int&`）：只能**读取**，不能修改。专供 `const` 对象调用（如作为函数参数传入时）。
- **感觉没区别的原因**：平时测试用的都是普通对象，永远走的是非 const 版本；一旦对象被 `const` 修饰，第二个版本就必不可少，否则编译报错。
- **本质**：这两个重载区分了“读权限”和“写权限”，是 C++ 类设计的基本规范。

```cpp
class SeqList {
    int* data;
    int  size;
public:
    // 非 const：可读可写
    int& operator[](int i)       { return data[i]; }
    // const：只读，供 const 对象使用
    const int& operator[](int i) const { return data[i]; }
};

void print(const SeqList& s) {
    // s 是 const，必须走 const 版本，否则编译报错
    std::cout << s[0];
}
```

## 二、CMD 命令行操作要点（文件与目录查看）

| 想要的操作 | CMD 命令 (Win) | 对比 Linux/Mac（提醒） |
| :--- | :--- | :--- |
| **查看当前目录路径** | `cd` 或 `echo %cd%` | Linux 用 `pwd`（CMD 中无效） |
| **查看当前目录下的文件** | `dir` | Linux 用 `ls`（CMD 中无效） |
| **只显示文件名（简洁）** | `dir /b` | - |
| **筛选特定类型文件** | `dir *.exe`（查看生成的程序） | - |
| **显示隐藏文件** | `dir /a` | - |
| **分页查看（内容太多时）** | `dir /p` | - |

> **注意**：如果用的是 PowerShell，则 `ls` 和 `pwd` 都能用，但 **CMD** 原生只认 `dir` 和 `cd`。

## 三、综合实战流程（数据结构学习场景）

结合学数据结构的场景，完整流程如下：

1. 写完 C++ 代码（比如顺序表）后，**编译**生成 `.exe`。
2. 在 CMD 中先用 **`cd`** 确认当前路径是不是 `.exe` 所在目录。
3. 再用 **`dir *.exe`** 确认文件是否生成。
4. 运行程序时，如果发现数据错乱，回头检查是否忘了在 `new int[n]` 后面加 **`()`** 来清零。
5. 设计类时，记得把 `operator[]` 写两个版本，这样顺序表才能像真正的数组一样，既能在普通场景修改，也能在 `const` 场景安全读取。

```
编译 ──► cd 确认目录 ──► dir *.exe 确认生成 ──► 运行
                                                  │
                                  数据错乱? ──► 查 new int[n]() 是否清零
                                  类设计?   ──► 查 operator[] 是否双版本
```
