# 数据库结构文档

> 生成时间：2026-07-27
> 数据库：SQLite（`backend/data.db`），ORM：SQLAlchemy
> 模型源码：`backend/app/models/user.py`（users）、`backend/app/deck/models.py`（deck_* 全部表）
> 契约参考：`frontend/lib/api/deck/types.ts`、`docs/backend-api/01-target-design.md`

## 总览

共 19 张表：`users` + 18 张 `deck_` 前缀表 + `alembic_version`（迁移版本记录，略）。
训练舱全部新表以 `deck_` 为前缀；旧系统表已物理删除。

按域分组：

| 域 | 表 |
|---|---|
| 用户 | `users` |
| 知识点与掌握度 | `deck_knowledge_points`、`deck_mastery_events`、`deck_user_mastery`、`deck_ability_axes` |
| 代码审查室 | `deck_review_sessions`、`deck_injected_defects`、`deck_review_attempts` |
| 调试竞技场 | `deck_arena_challenges`、`deck_arena_attempts`、`deck_arena_ratings` |
| 苏格拉底导师 | `deck_tutor_messages` |
| 认证 | `deck_cert_exams`、`deck_cert_questions`、`deck_certifications` |
| 经济与成长 | `deck_core_transactions`、`deck_daily_activity`、`deck_user_badges` |
| 动态流 | `deck_feed_events` |

实体关系简图：

```
users ──┬── deck_ability_axes            (1:N, 按轴一行)
        ├── deck_mastery_events          (1:N) ──> deck_knowledge_points
        ├── deck_user_mastery            (1:N) ──> deck_knowledge_points
        ├── deck_review_attempts         (1:N) ──> deck_review_sessions ──> deck_injected_defects
        ├── deck_arena_attempts          (1:N) ──> deck_arena_challenges
        ├── deck_arena_ratings           (1:1)
        ├── deck_tutor_messages          (1:N)
        ├── deck_core_transactions       (1:N)
        ├── deck_certifications          (1:N)
        ├── deck_daily_activity          (1:N, 按天一行)
        ├── deck_user_badges             (1:N)
        └── deck_feed_events             (1:N)

deck_cert_exams ──> deck_cert_questions  (1:N)
```

## 1. 用户

### `users`

认证与档案主表，同时承载平台货币（智核）与学习档案聚合字段。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | VARCHAR(36) | PK | UUID 字符串 |
| email | VARCHAR(255) | NOT NULL, UNIQUE（ix_users_email） | 邮箱 |
| username | VARCHAR(100) | NOT NULL, UNIQUE（ix_users_username） | 用户名 |
| hashed_password | VARCHAR(255) | NOT NULL | 密码哈希 |
| is_active | BOOLEAN | NOT NULL | 是否激活 |
| is_admin | BOOLEAN | NOT NULL | 是否管理员 |
| is_test_account | BOOLEAN | NOT NULL | 测试账号（前 3 次竞技场练习免验证） |
| cores | INTEGER | NOT NULL, 默认 100 | 智核余额（平台货币），唯一变动途径见 `deck_core_transactions` |
| cores_total_earned | INTEGER | NOT NULL, 默认 100 | 累计获得智核（含初始 100） |
| cores_total_spent | INTEGER | NOT NULL, 默认 0 | 累计消耗智核 |
| xp | INTEGER | NOT NULL, 默认 0 | 经验值（签到等） |
| mastery_xp | INTEGER | NOT NULL, 默认 0 | 精通之路经验（测验） |
| mastery_level | VARCHAR(20) | NOT NULL, 默认 '入门' | 精通等级：入门/学习/练习/熟练/精通 |
| streak_days | INTEGER | NOT NULL, 默认 0 | 当前连续学习天数 |
| last_activity_date | DATETIME | NOT NULL | 最近活动时间 |
| total_checkin_days | INTEGER | NOT NULL, 默认 0 | 累计签到天数 |
| preferred_languages | JSON | NOT NULL, 默认 [] | 偏好编程语言列表 |
| total_exercises | INTEGER | NOT NULL, 默认 0 | 累计完成练习数 |
| correct_exercises | INTEGER | NOT NULL, 默认 0 | 累计答对练习数 |
| accuracy_rate | FLOAT | NOT NULL, 默认 0.0 | 正确率（%） |
| courses_enrolled | JSON | NOT NULL, 默认 [] | 已选课程 ID 列表（旧系统遗留字段） |
| weak_points | JSON | NOT NULL, 默认 [] | 薄弱知识点列表 |
| preferred_difficulty | INTEGER | NOT NULL, 默认 2 | 偏好难度（1–5） |
| created_at | DATETIME | NOT NULL | 创建时间 |
| updated_at | DATETIME | NOT NULL, onupdate | 更新时间 |

## 2. 知识点与掌握度

掌握度模型为**事件源 HLR**：`deck_mastery_events` 是事实源，`deck_user_mastery.p_l/level` 只是重放推导出的缓存读模型。新增掌握度逻辑一律写事件 + 重算，禁止固定 delta 直改 `p_l`。

### `deck_knowledge_points`

知识点（种子内置，按三轴分组）。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | VARCHAR(36) | PK | UUID |
| name | VARCHAR(100) | NOT NULL, UNIQUE | 知识点名 |
| category | VARCHAR(100) | NOT NULL | 分类 |
| axis | VARCHAR(20) | NOT NULL | 所属轴：review / debug / implement |
| key_points | JSON | NULL | 费曼检验评分要点：`[{"keys": [同义词...], "label": 要点名}]` |

### `deck_mastery_events`

掌握度事件流（事实源）：每次答题/检验一条，`p_l` 与 `level` 由它重放推导。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | VARCHAR(36) | PK | UUID |
| user_id | VARCHAR(36) | NOT NULL, FK → users.id, 索引 | 用户 |
| kp_id | VARCHAR(36) | NOT NULL, FK → deck_knowledge_points.id, 索引 | 知识点 |
| created_at | DATETIME | 默认 utc_now | 事件时间 |
| source | VARCHAR(20) | NOT NULL | 来源：review_gym / arena / feynman / certification / placement |
| correct | BOOLEAN | NOT NULL | 是否正确 |
| grade | VARCHAR(10) | NULL | 费曼评级 |
| hints_used | INTEGER | NOT NULL, 默认 0 | 使用提示次数 |
| latency_ms | INTEGER | NULL | 作答耗时（毫秒） |

### `deck_user_mastery`

用户知识点掌握度缓存。存在任意行即视为已定级（has_placement）。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| user_id | VARCHAR(36) | PK, FK → users.id | 用户 |
| kp_id | VARCHAR(36) | PK, FK → deck_knowledge_points.id | 知识点 |
| p_l | FLOAT | NOT NULL, 默认 0.5 | HLR 回忆概率 |
| level | VARCHAR(10) | NOT NULL, 默认 '初识' | 掌握等级：初识/熟悉/熟练/精通 |
| updated_at | DATETIME | NOT NULL, onupdate | 更新时间 |

联合主键 `(user_id, kp_id)`。

### `deck_ability_axes`

三轴经验。等级 = `1 + xp // 400`，`xp_next = level * 400`。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| user_id | VARCHAR(36) | PK, FK → users.id | 用户 |
| axis | VARCHAR(20) | PK | 轴：review / debug / implement |
| xp | INTEGER | NOT NULL, 默认 0 | 该轴经验值 |

联合主键 `(user_id, axis)`。

## 3. 代码审查室（Review Gym）

### `deck_review_sessions`

审查关卡（种子内容）。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | VARCHAR(20) | PK | 形如 `REVIEW-0247` |
| title | VARCHAR(100) | NOT NULL | 标题 |
| language | VARCHAR(20) | NOT NULL | 语言 |
| code | TEXT | NOT NULL | 待审查代码 |
| defect_count | INTEGER | NOT NULL | 注入缺陷总数 |
| difficulty | INTEGER | NOT NULL | 难度 |
| eta_minutes | INTEGER | NOT NULL | 预计用时（分钟） |
| related_weakness | VARCHAR(100) | NULL | 关联薄弱点 |

### `deck_injected_defects`

注入缺陷（**服务端秘密，绝不下发**）。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | VARCHAR(36) | PK | UUID |
| session_id | VARCHAR(20) | NOT NULL, FK → deck_review_sessions.id, 索引 | 所属关卡 |
| line | INTEGER | NOT NULL | 缺陷所在行 |
| type | VARCHAR(20) | NOT NULL | 缺陷类型 |
| explanation | TEXT | NOT NULL | 缺陷解释 |

### `deck_review_attempts`

审查提交记录（幂等键 `user_id + session_id` 由 service 层保证）。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | VARCHAR(36) | PK | UUID |
| user_id | VARCHAR(36) | NOT NULL, FK → users.id, 索引 | 用户 |
| session_id | VARCHAR(20) | NOT NULL, FK → deck_review_sessions.id | 关卡 |
| marks | JSON | NOT NULL | 用户标记的缺陷行列表 |
| verdict | JSON | NOT NULL | 判定结果 |
| created_at | DATETIME | NOT NULL | 提交时间 |

## 7. 经济与成长

### `deck_core_transactions`

智核一本账（唯一变动途径）。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | VARCHAR(36) | PK | UUID |
| user_id | VARCHAR(36) | NOT NULL, FK → users.id, 索引 | 用户 |
| delta | INTEGER | NOT NULL | 变动量（正为获得，负为消耗） |
| reason | VARCHAR(200) | NOT NULL | 变动原因 |
| balance_after | INTEGER | NOT NULL | 变动后余额 |
| created_at | DATETIME | NOT NULL | 时间 |

### `deck_daily_activity`

每日活动（节奏柱图 / 今日统计 / 连续天数）。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| user_id | VARCHAR(36) | PK, FK → users.id | 用户 |
| day | DATE | PK | 日期 |
| minutes | INTEGER | 默认 0 | 学习分钟数 |
| exercises | INTEGER | 默认 0 | 练习数 |
| correct | INTEGER | 默认 0 | 答对数 |

联合主键 `(user_id, day)`。

### `deck_user_badges`

已解锁徽章（事实表）。徽章定义**不入库**，判定引擎见 `backend/app/deck/badges.py`。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INTEGER | PK, autoincrement | 自增 ID |
| user_id | VARCHAR(36) | NOT NULL, FK → users.id, 索引 | 用户 |
| badge_id | VARCHAR(40) | NOT NULL | 徽章 ID（代码内定义） |
| unlocked_at | DATETIME | NOT NULL | 解锁时间 |

唯一约束 `uq_deck_user_badge (user_id, badge_id)`，保证幂等。

## 附注

- 所有 `created_at` / `updated_at` 使用 UTC（`app.utils.time.utc_now`），`updated_at` 带 `onupdate` 自动刷新。
- 外键均指向 `users.id` 或对应种子内容表主键；SQLite 侧未建级联规则。
- 索引：除上表标注的唯一索引与唯一约束外，各流水表均在 `user_id`（及相应 `session_id` / `exam_id` / `kp_id`）上有普通索引，用于按用户/内容查询。
- `alembic_version` 表记录迁移版本号（VARCHAR(32) 主键），无业务含义。
