# GAI Teaching Boundary For Defense

## Core Position

WisdomPilot is not an uncontrolled AI-generated curriculum system. Its reliable backbone is deterministic: courses, exercises, judging, progress, rewards, wrong-question collection, leaderboards, and statistics are owned by normal application services and tests.

## What GAI Does

GAI is used as a controlled assistant at bounded learning moments:

- tiered hints for programming exercises;
- choice/explanation support;
- code feedback;
- optional reflection or remedial prompts;
- teacher-facing or admin-facing configuration and demonstration support.

## What GAI Does Not Decide

GAI does not decide reward-bearing correctness, leaderboard rank, tier promotion, core balance, or authoritative challenge completion. Those decisions are made by deterministic services and backend-authoritative judging.

## Why This Is Safer

The architecture avoids depending on current AI models for facts that must be correct. AI can help learners think, but deterministic services decide state changes that affect grades, progress, rewards, or analytics.

## Demo Story

The recommended defense demo path is:

1. learner enters challenge path;
2. learner writes and runs code;
3. backend performs authoritative submission verification;
4. progress unlocks and rewards update;
5. AI hints remain bounded by hint level, cache policy, and core cost;
6. statistics and ranking reflect deterministic state changes.
