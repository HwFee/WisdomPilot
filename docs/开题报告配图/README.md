## 各图内容说明

### 图1 系统总体架构
三层架构自顶向下：**表现层（Next.js 15 · React 19 · TypeScript · Tailwind · Monaco）** → **应用层（后端 FastAPI：代码审查室 / 调试竞技场 / 导师与费曼检验 / 认证考试 + 个性化调度引擎 + HLR 掌握度引擎 + 智核经济·徽章）** → **基础设施层（SQLite WAL · Judge0 判题 · AI 大模型 DeepSeek/OpenAI）**，侧注 JWT 认证 · 请求限流。对应报告 §4「前后端分离」描述。

### 图2 个性化调度流程
新用户 → 定级测试（5 分钟）→ 三轴初始等级 → 每日主任务按**最低能力轴**分发 → 训练模块（审查/竞技/费曼）→ 回忆概率低于阈值进复习队列 → 弱点知识点优先复习 → 事件回写闭环。对应报告 §4 最后一段。

### 图3 四级掌握状态机
初识 → 熟悉 → 熟练 → 精通，迁移条件分别为 p≥0.3 / p≥0.6 且答对≥3 / p≥0.8 且答对≥4 且间隔重复≥3 天且实战来源；虚线回退「遗忘 · p 下降」。对应 mastery.py 真实判定逻辑（PROFICIENT_MIN_CORRECT=3、MASTER_MIN_CORRECT=4、SPACED_PAIR_GAP_DAYS=3.0、PRACTICAL_SOURCES）。

### 图4 HLR 遗忘曲线
- **AI 版**：`p = 2^(−Δ/h)` 示意图，直观展示半衰期与遗忘速度关系。**当前已嵌入文档采用此版**（2026-08-15 由本人选定）。
- **精确版**（`04_hlr_curve_exact.png`，matplotlib 精确计算）：三条曲线 h=1 / 3.24 / 5.83 天（对应初始 → 复习 1 次 → 复习 2 次），标注 Δ=h 时 p=0.5，右侧四档掌握度阈值带。留作备选，如需换回可随时替换。
- 参数来源：`backend/app/training/mastery.py`（INITIAL_HALF_LIFE_DAYS=1.0、HALF_LIFE_GROWTH=1.8）。

### 图5 掌握度事件溯源
五个事件源（审查/竞技/费曼/认证/定级）→ `deck_mastery_events` 事件表（唯一事实源，追加写）→ HLR 纯函数重放引擎 → `deck_user_mastery` 读模型（p_l / 等级）→ 个性化调度、徽章、仪表盘消费。对应报告 §4「数据设计」的事件溯源架构决策，是系统区别于传统存读数的技术亮点。
