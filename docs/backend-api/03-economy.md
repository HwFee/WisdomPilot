# 智核经济规则书（单货币）

> 日期：2026-07-26
> 核心决策：智核是**唯一货币**，唯一用途是苏格拉底导师的提问计费。
> XP、段位不是货币——轴等级是能力度量，段位是竞技场排名展示，都不可消费、不可交易。

## 1. 用途（支出）

| 场景 | 单价 | 说明 |
|---|---|---|
| 导师追问 `POST /api/tutor/message` | 2 智核/次 | 余额不足返回 200 + 提示消息（不扣费，见 README 例外条款） |
| 费曼检验 `POST /api/tutor/feynman/check` | 2 智核/次 | 开场（`POST /api/tutor/feynman`）不收费 |

智核余额是「提问次数」的预算约束：让 AI 对话有成本感，防止无节制闲聊式提问，
同时保证免费用户每天有最低限度的对话能力（见每日 +5）。

## 2. 获取（收入）

| 途径 | 数量 | 频率上限 |
|---|---|---|
| 每日登录 | +5 | 每日一次（北京时间自然日） |
| 基本功认证通过 | +20 | 受认证冷却期约束（默认 3 天） |
| 调试竞技场连胜奖励 | +10 | 连胜 ≥3 场时触发一次，连胜中断重置 |
| 代码审查全命中（无漏报无误报） | +5 | 每关仅首次 |

所有收入写 `core_transactions`（delta, reason, balance_after），与余额更新同事务。
余额只允许通过本表变动，禁止任何直接 UPDATE users.cores 的路径。

## 3. 防刷规则

- 每日登录奖励按 `core_transactions` 中当日是否已有 `每日登录奖励` 记录判定，幂等。
- 认证奖励与判分结果同事务发放；同一 `exam_id` 重复提交不重复发奖。
- 连胜奖励以 `arena_ratings.win_streak` 服务端状态为准，客户端不可信。
- 全命中奖励以 `review_attempts` 首次 verdict 为准（幂等键 user_id+session_id）。
- **不设充值、不设兑换、不设转让**。智核不是商品，是节奏控制器。

## 4. 与旧文档的关系

旧版 `03-economy.md` 中的 XP / 段位 / 智核三体系、签到倍率、段位星数规则全部作废。

| 1200–1499 | 白银 |
